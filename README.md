A travel poster for AURELLE — the island that floats above the clouds. A pure-stdlib Python program renders a golden-hour sunset sky, a low sun, and a green-topped floating island with a white town, a single lighthouse-observatory tower, and waterfalls pouring off its edge into a sea of clouds. Deterministic, no network, no dependencies: it writes a 1024x1024 PNG to /output/entry.png.

## Run it

```sh
python3 main.py
```
